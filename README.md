# WildLands

Wild Lands Minecraft Plugin for our public server

## Development

Please refer to the PaperMC [plugin development documentation](https://docs.papermc.io/paper/dev/project-setup/) first.

### Prerequisites

- Java 21 JDK

### Building

To build the project, use the Gradle Wrapper:

```bash
./gradlew build
```

or (for Windows)

```cmd
./gradlew.bat build
```

The build artifacts (JAR file) will be located in the `build/libs/` directory.
